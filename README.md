> 一个"因为不完美，所以完美"的乌托邦。

## 一句话简介

KaluoreWorld 是一个类似乌托邦的世界：人们很少发生战争，更不会发生毁灭性的战争，全世界使用 **Kalupack** 语言交流。

它之所以如此完美，其实是因为它非常不完美：它本来只是一个**临时品**，却误打误撞成了人类的家园。

## 时间线

### 3728 年：地球的终结

- 人类长期污染环境，臭氧层日渐稀薄，直到彻底消失。
- 强烈的阳光和缺失的氧气，使人类无法在地表生存。
- 由于种种原因，人类也无法前往其他星球。

### 地下的人造地球

- 人类在地下建造了一个**人造地球**来生存，同时研究**空间压缩技术**。
- 原计划：研究完成后，压缩一艘飞船，前往更好的星球。

### 意料之外的敌人

- 所有人都全心研究技术，却没想过：人造地球外面，会不会长出新的生命？
- 曾有人提出这个问题，得到的回答都是"不可能"。
- 但它真的发生了：一种**紫红色、触手状的智慧植物**在恶劣的地表生长。因为环境恶劣，它们极其强大。
- 植物的根系越扎越深，**刺破了人造地球的天空**。
- 触手顺着根系往下，发现不对劲后，通过吸盘**喷出有毒气体**。
- 约 **70%** 的人类被气体夺走理智，开始自我毁灭。
- 剩下的人尝试攻击植物，但完全无效。重点很快从"攻击"变成了"活命"。

### 最后的方案：复制地球

- 幸存者用**尚未完成、不完善**的空间压缩技术，复制了一份 **2000 年的地球**。
- 这份复制品被放在真实地球的**地心**里，由地心能量驱动空间压缩。
- 复制地球里的人类，**基因被修改**，使他们尽可能和平。
- 这不是长久方案：不完善的空间压缩技术，**只能维持 1000 年**。

## 核心设定

### 1. 一艘有期限的"船"

KaluoreWorld 不是终点。1000 年后，空间压缩失效，这个世界会**直接爆炸**。

所以里面的人类必须在期限内：

1. 发现自己活在假世界里
2. 发展出足够的技术
3. 通过**黑洞入口**，走进真实的宇宙

> 如果他们一直发现不了，1000 年后人类就 Game Over。

### 2. 为什么没有战争？

和平有**两层保险**：

| 层面 | 原因 |
| --- | --- |
| 天性 | 基因被修改，天生倾向和平 |
| 理性 | 他们是**全人类的种子**，没有备份；而且时间有限，拿时间去战争，人类就完了 |

### 3. 模拟的宇宙

复制地球被连接到一个**模拟出来的宇宙**。人类会在未来一步一步地提示里面的人：你们身处一个假的世界。等他们有能力后，再把**黑洞作为入口**，让复制地球连接到真实的宇宙。

### 4. 超级 AI：世界的管理者

- 管理者是一个**融合了从古至今所有人类智慧的超级 AI**。
- 这个 AI，就是**编辑、优化、添加故事的每一个人**。

AI 暗示人类，而不是直接告诉他们，原因有两个：

- 怕他们**一直发现不了**，1000 年后假地球爆炸，人类 Game Over。
- 暗示要循序渐进，不能太猛，否则可能引发恐慌。
